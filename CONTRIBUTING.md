# Contributing

Run `build.ps1` and `run-tests.ps1` before submitting code. Keep brand policies separate, preserve signature checks, recovery limits and rollback.

Use synthetic fixtures. Do not commit machine reports, enrollment state, real-device screenshots or personal identifiers.

For issues, describe software versions and reproduction steps. Share hardware details only if necessary and you are comfortable making them public. Distinguish simulated tests from physical lighting and restart results.
